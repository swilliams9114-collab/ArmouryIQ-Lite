# ArmouryIQ Lite

ArmouryIQ Lite is a local-first Torn faction armoury intelligence userscript designed for TornPDA and compatible userscript managers.

## Features

- Embedded faction Armoury dashboard
- Configurable three-letter item picker and whitelist
- Stock targets, low-stock levels, and critical levels
- Restock quantities and estimated market costs
- Local inventory snapshots and usage estimates
- Loan-limit monitoring and alerts
- Copyable staff reports
- Local backup, restore, and diagnostics
- Dedicated custom Torn API-key setup

ArmouryIQ Lite does not require Google Sheets, Cloudflare, D1, or another external database. API keys, settings, and history remain in the userscript manager on the installed device.

## Installation

Install the current release from Greasy Fork. The GitHub repository is the source of truth, while Greasy Fork provides installation and updates to TornPDA.

## Privacy

The script does not contain or publish a user's Torn API key. Exported backups and copied reports also exclude the API key.
